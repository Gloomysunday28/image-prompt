# 平台发布适配

官方入口与资料核对日期：2026-09-15。后台多需登录；入口可访问不代表已验证登录后投稿流程。字段、权限和限制在执行时读取实际页面。

## 抖音 · douyin

- 2026-09-16 已实测完整浏览器投稿流程，操作步骤见 [douyin-browser.md](douyin-browser.md)。当前没有独立抖音脚本。
- 官方入口：[抖音创作者中心](https://creator.douyin.com/)。从导航进入视频发布和作品管理。
- 对应页面实际的标题/描述/话题字段填写；话题需要选中时核对已真正添加。
- 检查当前可用封面、可见性、定时和内容声明。不为未出现的功能寻找非公开接口。
- 提交后到作品管理核验实际状态，分别记录审核中与已发布。

## TikTok · tiktok

- 官方入口：[TikTok Studio](https://www.tiktok.com/tiktokstudio)。从当前导航进入 Upload。
- 官方参考：[创作者工具](https://support.tiktok.com/en/using-tiktok/creating-videos/creator-tools-on-tiktok)、[TikTok Studio 介绍](https://newsroom.tiktok.com/helping-creators-bring-creativity-to-life-with-tiktok-studio?lang=en)。
- 描述、hashtags、封面、观看权限和互动选项按当前表单填写，不自动翻译文案。
- 内容披露和定时选项按当前账号确认。区域或权限受限时说明阻塞，不尝试绕过。
- 从内容管理核对公开、排期或审核状态，上传完成不代表公开可见。

## YouTube · youtube

- 官方入口：[YouTube Studio](https://studio.youtube.com/)，Create → Upload videos，控件名称随界面语言变化。
- 官方流程：[上传视频](https://support.google.com/youtube/answer/57407?hl=zh-Hans)。
- 独立填写标题与简介，保留用户署名和来源；tags 与描述里的 hashtags 分开处理。
- 核对频道，依据事实填写儿童受众、合成内容和商业合作等适用字段；不只凭动画风格判断儿童受众。
- 按页面完成 Details、Video elements、Checks、Visibility。Shorts 分类以当前平台规则及上传后显示为准，不能靠 `#Shorts` 保证。
- 明确 Private / Unlisted / Public / Schedule。要求平台草稿而只能保存私密视频时，记 `draft` 并注明实际是 Private；只允许本地草稿则不上传。
- 核验视频链接、可见性和时间；取得视频 ID 或保存私密视频不等于公开。

## bilibili · bilibili

- 官方入口：[哔哩哔哩创作中心](https://member.bilibili.com/)，从导航进入视频投稿、稿件管理。
- 官方参考：[社区公约与投稿规范](https://member.bilibili.com/studio/convention/)。
- 独立填写标题、简介、标签、分区和封面；根据真实内容选分区，原创/转载属性与来源按用户说明填写。
- 单视频默认单稿件；多文件不自动拼接或建多 P。合集、系列、联合投稿仅按用户指定使用。
- 读取当前页面定时和声明要求。提交后记录审核状态；BV/AV 标识出现时才记录，不推测作品链接。

## 微信视频号 · wechat_channels

- 官方入口：[视频号助手](https://channels.weixin.qq.com/)。2026-09-16 已通过浏览器工具完成真实上传、AI 标注、发表与公开状态核验；字段及限制以执行时页面为准。
- 已确认含 AI 生成内容的视频立即公开发表，默认使用 [微信视频号投稿脚本](wechat-channels-script.md)。其他类型按通用流程操作；不把微信公众号后台当作视频号入口。
- 复用可用登录会话；扫码或二次验证由用户完成。上传前核对目标视频号名称及页面可见的稳定账号标识，`account_id` 记录视频号标识，`account_label` 记录名称；不能拿扫码操作者的微信昵称代替目标视频号。无法取得稳定标识时如实留空，并在恢复时重新确认账号。
- 等待页面明确完成上传及必要处理。按实际表单分别填写描述、话题和可用的短标题；`description`、`tags` 保存实际内容，短标题保存到 `platform_fields.short_title`，`title` 保留清单中的作品标题。不存在独立标题栏时不要虚构已填写；用户指定文案超限时给出具体修订。话题需要选中时核对已真正添加。
- 封面使用用户提供的素材或平台默认封面，记录实际选择。原创、AI 合成、商业合作等声明按内容事实及当前页面填写，将页面实际提供的声明和设置存入 `platform_fields`，不臆造平台不存在的开关。
- 可见性、草稿和定时功能以当前账号实际界面为准。`draft` 必须有明确保存回执，留在编辑页不算已保存；`schedule` 核对完整日期、时间和页面时区，功能不可用时记录阻塞。关联商品、推广及额外分享不随普通发布开启。
- 提交一次后进入内容管理，刷新并核对账号、文案、提交时间、时长及预览；有作品 ID 时按 ID 核验。记录页面原始状态到 `evidence`。内容审核中记 `reviewing`，明确排期记 `scheduled`；转码或处理中且无法确定发布结果时记 `unknown` 并说明原因。原创声明审核与作品发布状态分别记录，不凭原创审核结果推断作品是否公开。
- 页面明确已发表/已发布、可见范围符合要求且作品可访问时才记 `published`。若作品只能在微信内核验而当前工具无法访问，保留待核实状态并说明；不要求为获取链接重新投稿。
- `post_id`、`post_url` 仅记录平台实际返回或分享入口取得的 ID、链接，不拼接猜测。拿不到公开链接时保留 `post_url: null`，记录真实 `management_url` 并标注为管理页；提交回执不明时遵循共用恢复规则，不再次上传。

## 百家号 · baijiahao

- 官方入口：[百家号创作平台](https://baijiahao.baidu.com/)。复用已有百家号标签页及登录状态，不把企业百家号推广页当作个人账号投稿入口。
- 2026-09-16 已核验登录后入口：发布作品 → 视频，实际页面为 `https://baijiahao.baidu.com/builder/rc/edit?type=videoV2&is_from_cms=1`；作品管理为 `https://baijiahao.baidu.com/builder/rc/content`。已实测真实视频上传、表单填写与提交；用户手动完成百度安全验证后自动提交，回执和作品管理均确认审核中。尚未核验审核通过后的公开访问。已确认含 AI 内容的视频立即投稿使用 [百家号投稿脚本](baijiahao-script.md)，其他类型才使用通用流程。新脚本通过隔离测试，尚未完成真实端到端投稿验证。
- 脚本从账号信息页 `/builder/rc/settings/accountSet` 核对可见名称及“百家号ID”，分别填 `account_label`、`account_id`，两者缺一不可。不拿头像文件名、昵称或自行添加的 URL 参数充当稳定账号 ID。
- 本次上传入口提示最多批量上传 10 个视频、单视频最大 12G、推荐 MP4 及大于 1080P 的资源；尺寸提示含 16:9、4:3、9:16、3:3。仅记录当时页面提示，执行时重新读取；入口提示不能证明 HEVC 等具体编码已通过转码。
- 本地运行产物与上传副本遵守主技能的系统临时目录规则。网站选文件若拒绝原路径，应使用 `tempfile.gettempdir()` / `os.tmpdir()` 返回的真实临时目录副本；本次 macOS 的 `/tmp` 被拒绝，而 `/var/folders/.../T/` 副本已被接受。只有真实临时路径仍被拒绝才记录工具权限阻塞；文件被接受仍不代表页面完成上传。
- 上传完成后按当前表单填写标题、简介、标签、封面及实际存在的创作声明；不要套用图文编辑器字段或编造视频页开关。AI、原创/转载、商业合作等依据素材事实填写，实际选项记录到 `platform_fields`；封面使用平台默认或用户提供的素材。
- 实测视频页使用“作品描述”富文本框，上传后默认带文件名。`fill` 可能追加而非覆盖：先聚焦、全选并删除默认文本，再填入文案，核对编辑器、预览及字符计数一致。当前创作声明弹窗含“含AI生成内容”，选择后点“确定”，再核验主表单值。平台自动提供横竖版封面。
- 点击发布后若出现“百度安全验证”滑块或扫码验证，保留当前表单等待用户手动完成；不要自动解验证码或重传。验证完成后先核对是否已自动提交及作品管理状态，再决定下一步。
- 按用户指定模式使用发布、存草稿或可用的定时功能；提交前持久化 `submitting`，只提交一次。作品管理按账号、标题、提交时间、时长及预览核验；出现作品 ID 后优先按 ID 查询。只有页面明确保存草稿才记 `draft`，审核中记 `reviewing`，发布且可访问才记 `published`；回执不明确记 `unknown`，不自动重传。
- `post_id` 与 `post_url` 只填平台实际给出的值，不猜测链接。没有公开链接时留空，并记录真实 `management_url`；进入上传页、选择文件或出现发布按钮都不算完成投稿。

## 共同处理

- 时长、大小、编码、字数、标签数限制读取当前表单或官方帮助。素材不符合时给出具体差距，不自动压缩覆盖原文件。
- 多种封面比例使用用户对应素材或平台现有默认封面；有素材修改授权才制作衍生文件。
- 常规选项按主技能默认值直接处理。必填事实缺少依据时记录缺项并完成其他准备，不发起例行确认；可选字段无资料可留空。
