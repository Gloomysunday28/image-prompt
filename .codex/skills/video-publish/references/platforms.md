# 平台发布适配

官方入口与资料核对日期：2026-09-15。后台多需登录；入口可访问不代表已验证登录后投稿流程。字段、权限和限制在执行时读取实际页面。

## 抖音 · douyin

- 官方入口：[抖音创作者中心](https://creator.douyin.com/)。从导航进入视频发布和作品管理。
- 对应页面实际的标题/描述/话题字段填写；话题需要选中时核对已真正添加。
- 检查当前可用封面、可见性、定时和内容声明。不为未出现的功能寻找非公开接口。
- 提交后到作品管理核验实际状态，分别记录审核中与已发布。

## 快手 · kuaishou

- 官方入口：[快手创作者服务平台](https://cp.kuaishou.com/)。从导航进入视频发布、内容管理。
- 按表单的作品描述、话题、封面字段填写，不假设字段与抖音一一对应。
- 核对账号、可见性、定时能力和必要声明，等上传及页面要求的处理完成。
- 用内容管理中的对应稿件和状态核验结果，不只依赖短暂提示。

## TikTok · tiktok

- 官方入口：[TikTok Studio](https://www.tiktok.com/tiktokstudio)。从当前导航进入 Upload。
- 官方参考：[创作者工具](https://support.tiktok.com/en/using-tiktok/creating-videos/creator-tools-on-tiktok)、[TikTok Studio 介绍](https://newsroom.tiktok.com/helping-creators-bring-creativity-to-life-with-tiktok-studio?lang=en)。
- 描述、hashtags、封面、观看权限和互动选项按当前表单填写，不自动翻译文案。
- 内容披露和定时选项按当前账号确认。区域或权限受限时说明阻塞，不尝试绕过。
- 从内容管理核对公开、排期或审核状态，上传完成不代表公开可见。

## YouTube · youtube

- 官方入口：[YouTube Studio](https://studio.youtube.com/)，Create → Upload videos，控件名称随界面语言变化。
- 官方流程：[上传视频](https://support.google.com/youtube/answer/57407?hl=zh-Hans)。
- 独立填写标题与简介，保留用户署名和来源；tags 与描述里的 hashtags 分开处理。
- 核对频道，依据事实填写儿童受众、合成内容和商业合作等适用字段；不只凭动画风格判断儿童受众。
- 按页面完成 Details、Video elements、Checks、Visibility。Shorts 分类以当前平台规则及上传后显示为准，不能靠 `#Shorts` 保证。
- 明确 Private / Unlisted / Public / Schedule。要求平台草稿而只能保存私密视频时，记 `draft` 并注明实际是 Private；只允许本地草稿则不上传。
- 核验视频链接、可见性和时间；取得视频 ID 或保存私密视频不等于公开。

## bilibili · bilibili

- 官方入口：[哔哩哔哩创作中心](https://member.bilibili.com/)，从导航进入视频投稿、稿件管理。
- 官方参考：[社区公约与投稿规范](https://member.bilibili.com/studio/convention/)。
- 独立填写标题、简介、标签、分区和封面；根据真实内容选分区，原创/转载属性与来源按用户说明填写。
- 单视频默认单稿件；多文件不自动拼接或建多 P。合集、系列、联合投稿仅按用户指定使用。
- 读取当前页面定时和声明要求。提交后记录审核状态；BV/AV 标识出现时才记录，不推测作品链接。

## 共同处理

- 时长、大小、编码、字数、标签数限制读取当前表单或官方帮助。素材不符合时给出具体差距，不自动压缩覆盖原文件。
- 多种封面比例使用用户对应素材或平台现有默认封面；有素材修改授权才制作衍生文件。
- 必填选择缺少事实依据时，完成其他准备并合并询问；可选字段无资料可留空。
