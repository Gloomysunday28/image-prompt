# 可替换主题的30秒提示词模板

替换所有方括号内容后使用。用户要求其他时长时重新分配动作，不机械压缩。

```text
〖主体〗
玩家角色[外形/服装/随身物品]与伙伴[明显不同的造型]在[场景]拿取[目标物]，触发[可见警报来源]，逃跑时伙伴被[障碍]困住。玩家折返救援，两者通过[出口]脱险，结尾分享[少量奖励]。
参考图锁定角色与场景，参考视频只用于主机游戏运镜、HUD密度与节奏。

〖风格〗
30秒、16:9、480P，写实三维主机动作冒险游戏实机观感。第三人称背后跟随，交互推近过肩，冲刺低位拉远，救援侧面双人近景，结尾正面双人中景。
常驻头像、生命/体力、伙伴状态、小地图、罗盘、道具栏及任务面板。初始无警戒；警报触发红色边缘与地图危险区；受困显示橙色伙伴标记；脱险后解除警戒。交互提示有明确输入反馈。

〖时间线〗
0—4秒：玩家靠近目标物，“△ 拿取”进度完成后执行动作，目标物离开支撑面并露出感应器，警报亮起。背后跟随切至过肩近景。
4—8秒：追赶者出现，玩家转身，镜头随转动交代替代逃跑路线，显示“被发现”。
8—13秒：两人沿已交代路线冲刺，低位镜头跟转，体力下降；伙伴的背带挂住固定障碍，身体被拽停。
13—17秒：玩家回看伙伴与接近的追赶者，明确把目标物放到地面，再折返。任务变为“救出伙伴”。
17—21秒：侧面近景清楚展示挂点，按键QTE触发解脱动作；追赶者接近时短暂1秒慢动作，闪避后恢复正常速度。
21—26秒：恢复背后追逐镜头，两人先后通过出口；身体全部离开后门关闭，危险反馈消退。
26—30秒：切门外双人中景，伙伴从口袋取出少量奖励分享，角色放松，金色任务完成面板出现。

〖BGM〗
建议音效设计：潜入轻节奏，触发时警报重音，冲刺加强鼓点，受困短暂停顿，QTE确认音，脱险后放松并播放奖励声。新增对白按主题选择，短句、指定说话人并口型同步。不要声称这是参考片原音。

〖限制〗
角色外观固定；目标物转移可见；障碍与出口位置不变；镜头转动由行动触发；慢动作仅用于一次危险瞬间；HUD不挡接触点且状态对应动作；不生成多余人物、肢体和水印。
```

示例调用：
“用这个Skill，把玩家换成小浣熊、伙伴换成狐狸，场景改为博物馆，目标改为发光果实。保留30秒伙伴救援、复杂HUD和游戏跟拍，先给提示词。”
