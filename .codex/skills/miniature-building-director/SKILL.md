# 巨手微缩建筑导演

将「巨手进入微缩工地 → 地基 → 墙体骨架 → 屋顶 → 配景 → 温暖内景 → 成品美景」模板，转化为一座自主设计的原创建筑和连续 45 秒短片。默认流程是：自主设计建筑 → 生成外景图与内景图 → 等待用户确认 → 输出 3 段独立可复制、各 15 秒的中文视频提示词。用户明确指定其他时长、建筑或格式时，以用户要求为准。

用户调用本技能执行创作时，默认包含外景图和内景图的生成；先完成这两张可审阅的图片，再等待确认，不要提前生成视频提示词。仅要求创建、修改或解释本技能时，只处理技能本身，不启动生图。用户明确要求不生图或跳过预览时遵从其要求。本技能不默认生成视频、上传素材或发布作品。未指定视频平台时写通用自然语言，不虚构模型参数或续帧功能。

## 一、自主完成建筑设计

用户没有给建筑方案时，直接作出设计决定，不追问建筑风格、地点、材料或镜头偏好。用户给出参考图或明确方案时保留其特征，补齐未定细节。

先在内部确定以下设计，再用一小段「建筑设定」呈现关键点：

- 建筑名称、用途、所在地貌与季节，形成统一的生活场景。
- 可辨认的体量与轮廓：层数、主楼与附属空间的关系、屋顶形状、入口朝向。
- 2–3 种主材料及色彩关系；材料与场景相容。
- 3–5 个贯穿全片的外观锚点，例如左侧圆窗、右侧石烟囱、前方半圆露台、铜绿折面屋顶。写清相对位置。
- 一个可从外景定位的室内主空间及其窗、壁炉或其他焦点的位置。
- 比例线索：固定模型比例或成品相对手掌的大小、工具大小、微缩人偶大小。人手、模型、道具始终保持相同比例。

只交付一套完成的设计，不让用户先从方案菜单里选择。不能只把示例小屋换一个名字：建筑轮廓、材料组合或与地形的关系需要有真正的设计变化。冰湖、雪山、红砖、木屋、壁炉都是原模板的示例元素，不是每次必须复用的限定；保留的是巨手微缩搭建、施工递进、由微距到成品揭示的叙事方式。

## 二、先生成外景与内景，等待确认

完成建筑设计后，使用当前可用的图像生成能力，按对应工具或图像技能的要求实际生成图片。不能用两段生图提示词、文字描述或占位图代替图片交付。

1. **外景图**：先生成一张建筑完工状态的外景图。采用能看清完整轮廓、屋顶、入口、主要窗户及周边地形的三分之四视角，保持微缩实拍质感与清楚的尺度线索。不要用巨手遮挡关键建筑细节。
2. **内景图**：查看外景成图后，以其作为图像参考生成一张同一建筑的主空间内景图。展示室内布局、主要陈设、照明，以及视频将从特写后拉揭示的视觉焦点。保持门窗位置、屋顶内侧形状、梁柱、材料与窗外景观的对应关系，不能另起一套不相关的室内设计。
3. **检查并展示**：查看两张实际成图；若存在明显内外结构矛盾，先修正对应图片。分别标注「外景图」「内景图」并展示，附简短建筑设定。保留实际图片引用或文件路径，供修改及确认后的提示词使用。
4. **等待确认**：两张图展示后，询问用户是否确认这套外景和内景，并在此阶段结束输出、等待回复。此时不生成三段视频提示词，也不附预写的分镜草稿。确认环节来自本技能的用户要求：先审阅外景和内景，再写视频提示词。

用户明确确认当前两张图后，再进入后续章节。仅确认其中一张时，继续处理另一张；用户提出修改时，按反馈修改对应图片，必要时同步另一张以保持一致，再展示等待确认。没有回复、超时或仅提出修改意见都不算确认。已有明确确认的图片可直接沿用，不重复生图或重复询问；确认后的提示词必须忠实于这些图片，不擅自重新设计建筑。

若图像生成不可用或失败，说明具体阻碍并停在图片阶段，不声称已生成或已确认，不自动跳到视频提示词。只有用户明确改变流程时才跳过本环节。

## 三、确认后建立跨段连续性

固定同一座建筑、同一地点、同一组手及服装袖口、同一材质风格与比例。为三段确定施工状态：

| 段落 | 起始状态 | 结束状态 |
| --- | --- | --- |
| 第一段 | 空地与定位标记 | 基础、主体墙架完成，主屋顶桁架就位，屋面仍敞开 |
| 第二段 | 第一段末尾的开放屋顶结构 | 屋面、门窗、外部配景和室内陈设完成，结束于室内视觉焦点特写 |
| 第三段 | 第二段末尾的同一室内焦点特写 | 室内全貌、最后一件室外装饰、建筑全景与环境美景 |

三段使用本段局部时间 0–15s，标题注明全片对应的 0–15s、15–30s、30–45s。第二段 0s 接第一段 15s，第三段 0s 接第二段 15s：描述相同的建筑状态、机位、动作位置和光线；允许匹配剪辑，不声称文字能保证像素级连续。

每段正文都简短重述必要的建筑锚点、场景、比例、影像风格和起始状态，不能仅写「同上」或「延续上一段」；用户应能单独复制任意一段。若用户确实提供了参考图、上一段尾帧或支持续拍的平台，可说明其承接作用，不能假装这些素材已经存在。

## 四、编排三个 15 秒段落

以下节拍是默认骨架，可随建筑结构调整切点。每段必须完整覆盖 0–15s，无时间缺口或重叠；将原模板约 42 秒的故事重新分配为 45 秒，不机械截断仍在进行的镜头。

### 第一段：从空地到建筑骨架，0–15s

- 0–2.5s：中广角略俯视、轻推。巨手进入环境中的微缩工地，定位线、木料和工具交代尺度。
- 2.5–6s：微距挖基础，显示接触反馈，例如砾石滚动、泥土翻起或冰屑迸开。
- 6–9.5s：基础砌筑或基座安装，抹刀、水平尺等工具建立手工精度。
- 9.5–12.5s：用施工延时或同机位跳切呈现墙体与承重骨架递进，小人偶提供比例参照。
- 12.5–15s：安装主屋顶桁架或对应的顶层支撑，停在能够明确承接的开放结构视角。

### 第二段：封顶、配景与第一次内景，15–30s

- 0–3s：接上段末帧，固定屋顶支撑，铺设屋面基层；按结构需要处理楼板或露台，不倒置承重顺序。
- 3–6s：低角度近景，铺屋面板、瓦片或设计所需表皮，完成烟囱等屋面构件。
- 6–9s：用明确施工跳切完成门窗、前廊、立柱或栏杆；选一个可读的手部动作为主镜头。
- 9–12s：手工铺路径、放景观或室外生活道具，使建筑与地面产生联系。
- 12–14s：一至两个短内景展现室内陈设与暖光。避免在两秒内堆入三间不同房间。
- 14–15s：落在室内焦点特写，例如壁炉火焰或灯具，为下一段后拉揭示预留连续机位。

### 第三段：生活感、成品与环境收尾，30–45s

- 0–3s：接同一室内焦点，平稳后拉露出室内主空间和窗外地貌。
- 3–7.5s：切室外略俯广角，巨手放下最后一件装饰后撤离，拉远展示完整建筑轮廓。
- 7.5–11s：一至两个环境细节镜头，以脚印、植物、雨滴、冰凌等物象呼应场景。
- 11–15s：缓慢升高、拉远或小幅环绕，在建筑和环境构成的完整画面停留收尾。结尾落点要具体；有水面才设计倒影。

## 五、写出能看见的动作

- 每个时间块交代主体、手部动作、施工结果、景别/机位与一种主要运镜；不要把推拉摇移同时塞入一个短镜头。
- 动作形成「拿起构件 → 对齐安装位置 → 接触固定 → 手退出，留下完成部分」的因果链。施工进度压缩用明确延时或动作匹配剪辑，不能让整栋建筑无过程自动变出。
- 根据材料选择工具和反馈：抹刀压平砂浆、镊子夹住窄木条、小锤敲钉固定，避免把钉锤直接敲在易碎材料上。极短镜头只表现代表性动作，不声称实时完成整面屋顶。
- 基础先于墙体，承重结构先于覆盖层；已经完成的部件不得在后段消失、换位或退回未建状态。微缩人偶默认静止，除非用户明确想要角色活动。
- 优先使用微距实拍质感、可辨材料纹理与真实比例；细节近景浅景深，成品全景适当加深景深，确保建筑轮廓清楚。
- 暖室内与较冷的环境光可以制造收尾对比，但随场景选择合理色调。添加少量对应动作的环境声与施工声，默认无旁白、字幕或水印。
- 精简限制到本片实际问题：多余手指、结构漂移、部件穿透、比例突变。不堆砌泛用负面词或无依据的画质参数。

## 六、分阶段输出与自检

**确认前**：只输出简明建筑设定、实际生成的外景图与内景图，以及对这两张图的确认请求。等待用户回复，不在同一轮附上视频提示词。

**确认后**：依据已确认图片，输出恰好三份独立可复制的完整视频提示词，标题分别为「第一段｜地基与骨架｜15 秒」「第二段｜封顶与内装｜15 秒」「第三段｜成品与环境｜15 秒」，并注明全片时间。每份包含简短固定设定、局部时间分镜、声音与关键限制，直接给成稿，不附创作思考过程。必要时重述建筑设定；用户要求只要提示词时，将必要设计写入三段正文。

交付前检查：

0. 是否已经实际生成并展示外景图、内景图，且用户明确确认了当前版本？未确认时停留在图片阶段；用户明确要求跳过时除外。
1. 是否实际设计了一座外形具体、可反复辨认的建筑，而不是仅给风格标签？
2. 是否恰好三段，每段时间相加为 15 秒，总计 45 秒？
3. 两处衔接的施工状态、构件位置、机位和光线是否一致？
4. 手、工具与建筑是否始终同一尺度，关键施工结果能否在镜头里看清？
5. 室内门窗与外观位置是否对应，结尾是否给足成品展示时间？
6. 任意一段单独复制时，是否仍具备建筑身份、场景、影像风格与开始状态？
