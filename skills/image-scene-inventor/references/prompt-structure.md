# Prompt 结构

本 skill 自带的写法规范，不依赖任何外部 skill 或仓库文件。

## 三种输出形态

按路线选，不要混：

| 形态 | 适用路线 | 特征 |
| --- | --- | --- |
| **分节长文** | 宏大天宫、工业蒸汽武侠、机甲武侠、神话真人、都市巨兽、梦幻空灵、夏日治愈 | 按下面的节序逐段写，末尾带 Negative Prompt |
| **密集短段** | 复古手绘海报、日常 emo | 一段话写完，不分节；Negative Prompt 从简 |
| **参数化模板** | 体素游戏 | 可变值一律写成 `{argument name="变量名" default="可用默认值"}`，固定版式留在占位符之外 |

## 双语：每份 Prompt 都出中英两版

**中文版和英文版是同一份指令的两个语言版本，不是两次创作。**

- 两版的画幅、焦段、机位高度、距离、角度、主体占比、地平线位置、物体尺寸、光源数量与方向、材质清单、Negative Prompt 条目，必须**逐项对应**。任何一版里有、另一版里没有的信息，都是错的。
- 中文版按中文语序自然写，不要写成英文的翻译腔。
- 英文版按英文 prompt 的行业写法写，不要把中文逐字对译。用摄影和制片的标准术语：`eye-level`、`low-angle`、`24mm wide cinema lens`、`subject occupies ~15% of frame`、`horizon at 45% height`、`overcast key light from camera left`、`practical light source`、`shallow depth of field`、`motion blur`、`high-ISO grain`、`atmospheric perspective`、`specular highlights`、`subsurface scattering`、`rim light`、`anamorphic flare` 等。
- 体素游戏路线只出英文版（占位符语法本身是英文），但仍要附一段中文说明变量含义。
- 两版都各自完整，都能单独粘贴使用，都自带各自语言的 Negative Prompt。

## 什么叫专业的 prompt

- **可执行**：每一句都在规定一个模型能照做的决定。删掉所有"史诗""震撼""氛围感""大片质感"这类不产生任何具体结果的词。
- **有参数**：见下面的"数字是硬要求"。
- **有物理**：光源要有位置和数量，影子要对得上，反射要对得上，风、雨、雾、尘要朝同一个方向。写了湿表面就要写它怎么反光。
- **有主次**：一眼能看出谁是主角，其余元素明确退到从属位置。
- **有边界**：Negative Prompt 针对这条路线真正常犯的错，不是通用垃圾词堆砌。
- **不自相矛盾**：正向要求的东西不能出现在 Negative 里；同一个属性不能被规定两次。

## 分节长文的节序

只保留能决定一个可见结果的节。用不到的整节删掉，不要留空标题。

1. **画幅与媒介** —— 比例，加上这次的媒介与它的渲染语言（见下节）。一句话说完，全部是肯定句。
2. **视角与构图** —— 主体占画面百分比、地平线位置。摄影类媒介再加机位高度、与主体距离、俯仰角、焦段；插画类媒介改写透视收敛方式与前景遮挡比例。
3. **空间层次** —— 近景放什么、中景放什么、远景放什么、视线沿哪条线被送过去。
4. **主体** —— 解剖比例、姿态、视线、唯一的一个动作、剪影。
5. **服装 / 装甲 / 道具** —— 构造方式、材质、磨损、它和身体怎么发生力学关系。
6. **环境与尺度** —— 建筑或地貌的建造逻辑、纵深、以及"凭什么看出它很大"的那个参照物。
7. **天气与大气** —— 风、雨、雾、尘；它们必须朝同一个方向讲同一件事。
8. **光与色** —— 光源位置、强度、色温、它造成的每一道影子、冷暖关系、受控的色板。
9. **媒介质感** —— 摄影类写光学缺陷、运动模糊、噪点、镜头脏污；插画类写笔触、纸纹、色块边缘、轮廓线。这一节永远按当前媒介写，不要写错门。
10. **正向关键词块** —— 一小段英文补强，不超过一行半。
11. **Negative Prompt** —— 见下。

## 排除项只能出现在 Negative Prompt

**正向部分里不许出现任何否定句。** 不要写"这不是奇幻电影海报""不是外星飞船降临""不是宗教式神光"这类话。

理由是技术性的：图像模型对正向文本里的 `飞船`、`神光`、`海报` 这些 token 一样会产生注意力，负面定义写在正文里经常反而把它们召唤出来。所有排除项一律下沉到 Negative Prompt，并且**写成术语，不写成句子**：

- ✗ `画面里不应该出现任何宗教式的神光或飞船`
- ✓ `god rays, spacecraft, poster layout`

正向部分只说"是什么"。想挡掉海报感，就把构图、机位、焦段、光比写死；想挡掉神光，就把光源位置、数量、色温写死。**用具体规定去占位，比用否定去驱赶有效得多。**

## 媒介决定写法

媒介不是加在末尾的一个风格词，它决定整份 Prompt 该用什么语言：

| 媒介 | 正向里该写 | 正向里不该写 |
| --- | --- | --- |
| 实拍摄影 / 柔光胶片 | 焦段、光圈、快门、传感器噪点、景深、光学缺陷、物理反射 | 笔触、色块、轮廓线 |
| 2D 动画背景 | 轮廓线粗细、色块分层、平涂与渐变的分界、天空的色阶、云的成块方式 | 焦段、景深、镜头光晕、传感器噪点、物理渲染反射 |
| 水彩淡彩 | 纸纹、湿边、水痕、留白、透明叠色、晕开的边缘 | 焦段、景深、3D 光泽 |
| 厚涂数字插画 | 笔触方向、色块堆叠、边缘收笔方式、大结构明暗 | 焦段、传感器噪点 |
| 丝网印海报 | 限色套印、套版错位、粗铅笔轮廓、平色域 | 摄影术语、渐变过渡 |

**最常见的错误是给插画类媒介写摄影参数。** "24mm 广角"在 2D 动画背景里没有意义——那里控制视角要靠"地平线位置 + 透视线收敛程度 + 前景遮挡比例"来写。

## 数字是硬要求

凡是能决定构图的地方，写确切数字，不要用"史诗感""电影感"这类词代替。

所有媒介通用：

- 主体占画面百分比
- 地平线在画面高度的百分之几
- 画幅比例
- 关键物体的实际尺寸（棍长、台阶单级高度、生物体长）
- 主体之间的实际距离

只有摄影类媒介写这些：

- 焦段（20mm / 35mm / 50mm）、光圈、快门
- 机位离地高度、离主体距离、俯仰角

插画类媒介改写这些：

- 透视线的收敛程度（一点透视 / 两点透视 / 近似平行）
- 前景遮挡占画面的百分比
- 色块分几层、每层的明度差
- 轮廓线的有无与粗细

近远关系要写成可验证的事实（"最近的一只距人物约 8 米"），不要写成形容词。

## Negative Prompt 按路线选

原则：**只挡这条路线真正常犯的错，绝不否掉正向里要求的东西。**

- **实拍类（工业武侠 / 机甲 / 神话 / 巨兽）**：概念艺术、数字绘画、游戏截图、Unreal 渲染感、塑料皮肤、干净 CGI、魔法辉光、海报式构图、过度 HDR、过度锐化、不成立的建筑结构。
- **梦幻空灵**：海报排版、飞船元素、假雾、装饰性光柱、对不上的倒影、多个奇观同框、人造景深。
- **宏大巨构**：多座同等重要的建筑、灰糊远景、随机发光、园林摆件堆砌、航拍地图视角。
- **夏日治愈**：摆拍站姿、居中大头人像、平面化纵深、空荡天空、孤立对称的云、旅游快照感、阴郁调色。
- **插画类（复古海报）**：写实摄影术语、3D 光泽、色彩浑浊、矢量扁平、现代广告排版。Negative 写太长会把手绘感压掉，点到为止。
- **随手拍 emo**：磨皮美颜、影棚光、完美对称、时尚大片姿势、商业级完成度。
- **体素游戏**：HUD 缺失、第三人称身体、非体素几何、标题不可读、物品栏未指定。

## 成组图的额外规则

- 共享设定块在每张 Prompt 里**逐字重复**，一个字都不改。风格统一靠的是这个，不是靠"保持一致"这四个字。
- 一组里只允许一条轴变化。这条轴之外出现的任何差异，都是 bug。
- 每张的 Negative Prompt 也保持一致，除非变化轴本身要求松掉某一条（例如时段变化时不能再禁"暖色"）。

## 交付

- 直接给成品，不留 `[占位符]`——用户明确要可复用模板时除外。
- 中文版一个代码块、英文版一个代码块，各自完整，用户可以整段复制。
- 不在 Prompt 里夹杂解释、编号说明或对本规范的引用。
