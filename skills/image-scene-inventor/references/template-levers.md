# 模板杠杆表

模板之所以"打不开"，通常不是因为想法不够多，而是因为不知道**哪些部分动了就散架、哪些部分本来就是留给你改的**。

每条路线按三层写：

- **锁死**：这条路线的身份。动了它，出来的图就不再属于这个模板，风格一致性直接消失。
- **自由变量**：本来就该每张图都不一样的地方。默认从这里下手。
- **高收益改法**：能把同一个模板拍出完全不同气质的少数几个动作。种子里的「反差注入」优先落在这里。
- **失败信号**：说明这次改过头或改错方向了。

一次只推一个高收益改法。同时推两个以上，画面会失去主次。

---

## monumental-celestial · 宏大天宫仙城

- **锁死**：巨构安静、体量真实；人极小且只有一两个；大面积负空间；建筑摄影的人眼高度与 40–50mm 压缩；同一时刻只有一种慢速现象。
- **自由变量**：建筑处于什么状态（新建 / 荒废 / 拆解 / 迁移）、那唯一的现象是什么、构图偏向哪一侧、光的色温、水面有没有反射。
- **高收益改法**：
  - 给巨构一件正在进行的**日常杂务**（扫阶、晾晒、修补、换班），神性立刻变成生活感。
  - 把主殿从"被瞻仰"改成"被使用/被遗弃/被拆除"，同一栋建筑换一个时态。
  - 把唯一现象从"往下"改成"往上"或"往回"（雨向上落、云海后退），物理反常但保持连续。
  - 让渺小的人**背对**主殿在做别的事。
- **失败信号**：出现多座同等重要的宫殿、远景变成灰糊的城市剪影、随机发光特效、园林摆件堆砌、构图变成航拍地图。

## industrial-wuxia · 东方工业蒸汽武侠

- **锁死**：所有机械必须能被造出来（管、铆、链、闸、锅炉）；真人比例与磨损布料；20–24mm 宽银幕城市纵深；水/铁/木三种材质同框。
- **自由变量**：主角在做什么工种的事、城市的高度层（水面 / 桥面 / 屋顶 / 塔顶）、天气、一天中的时段、人流密度。
- **高收益改法**：
  - 把武侠动作换成**劳动动作**（修管、卸货、等闸、晾衣），江湖气从环境里出来而不是从姿势里出来。
  - 把机位从屋顶降到**水面高度**，整座城的压迫方向反转。
  - 让城市停机一次（停电、停汽、退潮），暴露平时看不到的结构。
  - 只拍两个人之间的距离，不拍打斗。
- **失败信号**：悬浮建筑、魔法机械、干净的 PBR 塑料表面、装饰性雾气、橙青调色、概念图天际线。

## biomech-wuxia · 生物机械剑圣

- **锁死**：可穿戴、可关节运动的结构；真人演员比例；城市是正常运转的现代都市；金属不自发光；黑色里必须有层次。
- **自由变量**：头部剪影、肩甲逻辑、织物与金属的比例、破损位置、主体在画面里占多少、天气。
- **高收益改法**：
  - 把主体占比从 60% 砍到 12%，同一套设定从"角色海报"变成"城市纪实"。
  - 把战斗时刻换成**装备的日常维护**（擦洗、调试、缠绷带、卸甲）。
  - 让周围的普通人**完全不看他**，孤立感比任何对峙都强。
  - 只拍反射（水面、玻璃幕墙、后视镜）里的他。
- **失败信号**：像游戏 NPC 立绘、超英式站姿、干净塑料甲、剑身自己发光、城市空无一人或全是同款高楼。

## myth-liveaction · 东方神话真人史诗

- **锁死**：正常人体解剖，力量靠透视和景深而不是变形；真实石料与金属；克制的 VFX；一个决定性的情绪拍点。
- **自由变量**：战前 / 战后 / 封印中 / 归来；机位高度；长兵器怎么入画；废墟的破坏程度；天气。
- **高收益改法**：
  - 把"高潮"换成**善后**：捡东西、插回兵器、坐下来、擦干净。
  - 把英雄换成一个**旁观者**的视角去看他。
  - 把兵器从"举起"改成"横放/拖行/插地"，重量感立刻真实。
  - 用一个错误的天气：神话战场上下一场安静的小雨。
- **失败信号**：华丽奇幻海报感、金色神光、梦幻云海、悬浮特效、神仙群像、招牌兵器变短变模糊。

## urban-kaiju · 都市巨兽灾难

- **锁死**：第一人称成人视高、街道内、近乎垂直仰拍；主体占 85–90% 且四肢出框；生物是活体组织，不是岩石/熔岩/铠甲；城市只作为尺度证据。
- **自由变量**：物种、它在干什么、人类锚点是哪一件、天气、它有没有看镜头。
- **高收益改法**：
  - 把"攻击"换成**生理行为**：喝水、抖毛、打瞌睡、挠痒、呼吸。
  - 让它**完全无视人类**，恐惧从"被针对"变成"被忽略"。
  - 把它拍成静止的、几乎像建筑的一部分。
  - 只留证据不留怪兽：一只落在马路上的巨大羽毛、一个积水的脚印。
- **失败信号**：拍到完整身体或全翅、怪兽被推远、变成天际线全景、嘴太小、变成通用恐龙或西方龙、剪影黑成一团、发光眼睛、雾把主体糊掉。

## dream-nature · 梦幻空灵天象

- **锁死**：先有一个可信的真实地点和真实机位，再放奇观；全画面只允许**一个**奇观；奇观必须和云、水、光、遮挡发生正确的物理关系。
- **自由变量**：地点、奇观种类、观者与镜头的距离、是背影还是第一人称、时间。
- **高收益改法**：
  - 把地点从"风景名胜"换成**极其平庸的地方**（加油站、停车带、公交站），落差就是全部力量。
  - 让人物背对奇观在做一件很小的事。
  - 把奇观压到只占天空的一角，其余留给普通世界。
  - 把奇观的光当作**主光源**去照亮人和地面，而不是当背景贴图。
- **失败信号**：海报排版感、飞船元素、多个奇观同框、人物太远看不出关系、水面反射和天上对不上、装饰性光柱。

## healing-travel · 夏日治愈旅行

- **锁死**：一个明确的前景运动 + 一条把视线送出去的路（公路 / 铁道 / 坡 / 岸线）；9:16 竖幅；干净空气、高饱和但自然的色彩关系；层次复杂的积雨云。
- **自由变量**：动作、地点、时段、主体占比、同行人数。
- **高收益改法**：
  - 把主体从 60% 缩到 15%，从"人物写真"变成"夏天本身"。
  - 把地平线压到 45% 以下，天空接管画面。
  - 把"出发"换成"最后一天"，同样的画面情绪整个翻转。
  - 用刚下过雨的反光地面代替晴天硬光。
- **失败信号**：站着不动摆拍、居中大头人像、明信片式的平面纵深、空荡荡的天空、孤立对称的两朵云、村子只在正中间、没有引导线的花丛。

## retro-poster · 复古手绘旅行海报

- **锁死**：铅笔笔触 + 丝网印色块；轮廓清晰；前景植物装饰框；一个移动中的交通工具；简洁天空。
- **自由变量**：目的地、交通工具、装饰框植物、配色方案、画面比例。
- **高收益改法**：
  - 换配色方案，比换目的地更能改变整张画的气质。
  - 把交通工具从"驶来"改成"驶离"。
  - 只用单色 + 一处高饱和点缀。
  - 把装饰框从植物换成人造物（晾衣绳、渔网、遮阳伞）。
- **失败信号**：写实摄影术语混进来、3D 光泽、色彩变浑、现代广告排版、Negative Prompt 写太长把手绘感压掉。

## candid-emo · 日常 emo 随手拍

- **锁死**：像是手机误拍出来的；不完美的光和构图；轻微偏冷的低饱和；没有摆拍痕迹；短段落英文即可。
- **自由变量**：场所、唯一光源、瑕疵类型、人物正在做的那件小事。
- **高收益改法**：
  - 换唯一光源，比换场景更能改变情绪。
  - 把人挪到画面边缘，中间留给一件普通物品。
  - 拍事情结束后的空镜（人刚走开、椅子还热）。
  - 让对焦落错地方。
- **失败信号**：磨皮美颜、时尚大片姿势、完美对称、影棚光、戏剧化电影感、商业级完成度。

## voxel-game · 体素游戏参数化截图

- **锁死**：第一人称视角 + 完整 HUD + 九格快捷栏 + 顶部 3D 标题；方块几何；真实光照与体积雾；所有可变值用 `{argument name="..." default="..."}` 占位。
- **自由变量**：世界主题、左右生物、手持物、HUD 数值、标题材质。
- **高收益改法**：
  - 用 HUD 状态讲故事（半血 + 氧气三格 = 一整个叙事）。
  - 让左右两侧生物是**敌对关系**而不是装饰。
  - 把手持物换成非武器（地图、水桶、望远镜），玩法感立刻改变。
  - 换标题材质去呼应世界主题。
- **失败信号**：HUD 缺失、出现第三人称玩家身体、非体素几何、标题看不清、物品栏没写清楚。

## 打开度自检

一个场景种子变成成品前，逐条过：

1. 这张图和这个模板的默认样张，**能不能一眼分辨**？分辨不出就说明只换了名词。
2. 高收益改法用了**恰好一个**吗？零个 = 没打开；两个以上 = 会散。
3. 「反差注入」是否真的落在画面上、能被看见？只写在脑子里不算。
4. 锁死项有没有被误伤？误伤了就退回来，改自由变量。
5. 画面里最强的那个元素是不是唯一的？次要元素有没有退到从属位置。
6. 一句话能不能把这张图说清楚？说不清就是塞太多了。
